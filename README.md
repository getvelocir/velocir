# Velocir

Velocir is a download manager for Windows and Linux.

This repository is where you can:

- **Report a problem.** Open an issue. Velocir's "Report this problem" button opens one here with the details filled in; read them before sending, and remove anything you would rather not share.
- **Read what changed** in each version, in [CHANGELOG.md](CHANGELOG.md).
- **Find releases**, when they are published here.

The source code is not published here.
